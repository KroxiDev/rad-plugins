`licenses/` directory are retained conservatively in full from the official toolchain.

System dependencies are dynamically linked, not bundled: GLib/GObject/GIO (LGPL-2.1-or-later)
and the C runtime. The audio plugin invokes the separately installed `/usr/bin/pactl`
(PulseAudio client for PipeWire/PulseAudio); pactl is not bundled. These programs
retain their own licenses. Inspect distribution packages for their source/notices.

The packaged plugin executables print these retained texts with `--licenses` without
connecting to audio, D-Bus or the RAD host. This document and the original copies
are included in the source distribution.

The `r-efi-6.0.0/AUTHORS` file contains the upstream licensing and copyright
notices; its crate does not ship separate LICENSE files. It is retained in full.
